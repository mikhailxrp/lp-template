# AGENTS.md — единая точка входа для AI-агентов (Codex, Antigravity и др.)

Этот файл синхронизирует поведение агентов в **OpenAI Codex**, **Antigravity** и других `AGENTS.md`-совместимых средах с **Claude Code** в рамках одного источника истины (`CLAUDE.md`, `.claude/rules/`, `.claude/skills/`).

---

## 1. Обязательное чтение перед стартом

Перед любой работой с кодом, вёрсткой, контентом или аудитом **прочитай целиком** (одним параллельным батчем, если среда поддерживает):

1. `CLAUDE.md` — главные правила проекта (не сокращай и не пропускай разделы GEO, a11y, чеклист и запреты; файл ~33 КБ, поэтому читается напрямую инструментом чтения файлов).
2. `.claude/rules/general.md` — универсальные принципы разработки.
3. `.claude/rules/lp-workflow.md` — правила взаимодействия с пользователем и рабочего процесса.

Приоритет правил: `.claude/rules/general.md` → `CLAUDE.md` → `.claude/rules/lp-workflow.md`. Все правила проекта важнее общих привычек агента.

---

## 2. Условные правила (аналог `paths:` в Claude Code)

Подключай (читай файл целиком) автоматически, как только задача касается указанных файлов:

- **SEO / GEO и контент** (`*.html`, `*.php`, `llms.txt`, `robots.txt`, `sitemap.xml`) → прочитай `.claude/rules/seo-geo.md`.
- **Посадка на WordPress, Stage 2** (`*.php`, `inc/**`, `template-parts/**`, `themes/**`, `plugins/**`) → прочитай `.claude/rules/wordpress.md`.

---

## 3. Обязательное правило работы с MCP Context7 (документация библиотек)

Не пиши код по памяти, если используешь API, опции, хуки, классы или методы сторонних библиотек и фреймворков.

**Когда обязательно обращаться к Context7 MCP:**
- при работе с **Bootstrap 5** (компоненты, data-атрибуты, JS API модалок/аккордеонов/коллапсов, утилиты сетки);
- при настройке **Owl Carousel** и **jQuery 3.x** (включая режим `noConflict` для WordPress);
- на Stage 2 при работе с **WordPress 6.x API** и **Redux Framework** (metaboxes, поля, репитеры, хуки);
- при оценке или подключении любой новой библиотеки/плагина (шаг «Библиотеки» в `START.md`);
- при любых сомнениях в актуальности синтаксиса, сигнатур или совместимости версий.

**Порядок работы с Context7 MCP:**
1. Сначала проверь зафиксированную версию библиотеки в `.docs/direction.md` (раздел «Библиотеки») или в `assets/*/vendor/`.
2. Вызови `resolve-library-id` для нужной библиотеки, затем `query-docs` с конкретным вопросом и учётом версии проекта.
3. Опирайся на полученную документацию, а не на устаревшие примеры из памяти.

**Если Context7 MCP не подключён или недоступен (например, offline-sandbox в Codex):**
1. Проверь официальную документацию через веб-поиск (если сеть доступна) или проверь реальный исходник/минифицированный файл в `assets/*/vendor/` (для установленных библиотек).
2. Если нет ни Context7, ни сети, а API вызывает сомнения — **не угадывай**; явно предупреди пользователя, какие места нужно сверить по документации или после подключения Context7 MCP.

## 4. Скиллы и соответствие команд

Все 5 проектных скиллов подключены в `.agents/skills/` (тонкие обёртки) и ссылаются на единый источник истины в `.claude/skills/`:

| Команда (Claude Code / `START.md`) | Вызов в Codex | Источник инструкции | Скрипт (если есть) |
| --- | --- | --- | --- |
| `/lp-block` | `$lp-block` | `.claude/skills/lp-block/SKILL.md` | — |
| `/lp-check` | `$lp-check` | `.claude/skills/lp-check/SKILL.md` | `node .claude/skills/lp-check/lp-check.mjs` |
| `/seo-files` | `$seo-files` | `.claude/skills/seo-files/SKILL.md` | `node .claude/skills/seo-files/seo-files.mjs` |
| `/seo-audit` | `$seo-audit` | `.claude/skills/seo-audit/SKILL.md` | `node .claude/skills/seo-audit/seo-audit.mjs` |
| `/wp-slice` | `$wp-slice` | `.claude/skills/wp-slice/SKILL.md` | `node .claude/skills/wp-slice/wp-slice.mjs` |

Если пользователь пишет команду в любом формате (`/lp-block` или `$lp-block`), активируй соответствующий скилл и выполни его `SKILL.md` из `.claude/skills/`.

## 5. Соответствие инструментов по окружениям

- **Запуск проверок и утилит:** выполняй в терминале из корня проекта через `node .claude/skills/<skill>/<script>.mjs` (без `npm` и `package.json`).
- **Визуальная проверка вёрстки (375 / 768 / 1440):**
  - **Claude Code:** Playwright MCP (если подключён) или DevTools пользователем.
  - **Antigravity:** встроенный субагент `browser` (Chrome DevTools).
  - **Codex:** Playwright MCP (если подключён); если браузерного инструмента нет — прогони `lp-check.mjs`, проверь адаптивные классы и медиазапросы в коде, и дай пользователю короткий чеклист ручной проверки в браузере (375 / 768 / 1440).
- **Документация библиотек:** Context7 MCP (приоритет №1, см. раздел 3) → веб-поиск → локальные файлы `assets/*/vendor/` или явное предупреждение.
